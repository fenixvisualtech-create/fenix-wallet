# 🔥 Fenix Wallet Pro v2.5

O **Fenix Wallet** é um aplicativo completo de controle financeiro pessoal, cartões de crédito, extratos bancários (OFX/CSV) e planejamento de gastos futuros, projetado para rodar no Computador e no Celular como PWA (Progressive Web App).

---

## 🌟 Principais Recursos

- 🦅 **Identidade Fenix Wallet:** Layout com tema carmim red glassmorphism em Modos Noturno e Claro.
- 💳 **Gerenciador de Cartões de Crédito:** Cadastro de múltiplos cartões com faturas e limites separados.
- 📑 **Leitor de Extratos Bancários Multi-Arquivos:** Importe até 5 arquivos `.OFX` ou `.CSV` de uma só vez (Nubank, Itaú, Inter, etc.).
- 📅 **Gastos Futuros & Contas a Pagar:** Agendamento com confirmação de baixa automática.
- 🎨 **10 Avatares Fênix em Estilo Geometric Minimalist:** Personalização de foto e dados do perfil.
- 💡 **Dicas Financeiras Inteligentes:** Análise automática de consumo.
- 🔒 **100% Privado e Seguro:** Todos os dados ficam salvos localmente no seu dispositivo.

## 🚀 Como Publicar no GitHub Pages (Grátis & 24/7)

1. Crie um novo repositório público no GitHub: [https://github.com/new](https://github.com/new)
2. No seu terminal na pasta do projeto, envie os arquivos:
   ```bash
   git init
   git add .
   git commit -m "Publicação Fenix Wallet Pro"
   git branch -M main
   git remote add origin https://github.com/SEU_USUARIO/fenix-wallet.git
   git push -u origin main
   ```
3. No repositório do GitHub, vá em **Settings** ⚙️ -> **Pages** -> Selecione a branch `main` -> **Save**.
4. Acesse seu app em: `https://SEU_USUARIO.github.io/fenix-wallet/`

## 📱 Como Instalar no Celular (PWA)

- **iPhone (Safari):** Abra o link, toque em **Compartilhar** ➔ **Adicionar à Tela de Início**.
- **Android (Chrome):** Abra o link, toque nos **3 pontinhos** ➔ **Instalar aplicativo** ou **Adicionar à Tela Inicial**.
